- 场景名称：慢 SQL / 缺失索引导致 DB CPU 飙升

## 观测到的异常信号（基于实测数据判定）

- 5xx 错误率从 0.00% 升至 15.74%（故障期实测）
- P99 从 199ms 恶化到 2028ms
- app_worker_busy 升至 16（worker 池接近饱和）
- app_conn_pool_in_use=10/10（连接池打满）
- db_cpu_percent 从 22.0% 升至 95.4%
- db_slow_queries_total 在故障期新增 364 次
- gateway_upstream_5xx_total 故障期新增 2436 次

## 预期信号与根因线索

- [预期信号] db_cpu_percent 逼近 100
- [预期信号] db_slow_queries_total 持续增长
- [预期信号] http_request_duration_ms_p99 进入秒级
- [预期信号] db_connections_used 升高（慢查询占用连接）
- [根因线索] 慢查询日志确认具体 SQL（慢查询 took 数千毫秒）
- [根因线索] 用 EXPLAIN 检查是否走了缺失索引导致全表扫描
- [根因线索] 对照 db_cpu_percent 与 QPS，评估是否加索引/改写 SQL
