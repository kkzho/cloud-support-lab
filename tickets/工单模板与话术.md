# 工单模板与客户话术

> 用于把"排障"包装成"客户可感知的专业服务"。可直接作为面试中"你如何与客户沟通"的作答素材。

---

## 一、工单标准字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 工单号 | 唯一标识 | #20260112-0031 |
| 客户/项目 | 客户名称与业务 | 某电商 / 订单服务 |
| 提交人 | 客户联系人 | 张工（运维负责人） |
| 严重级别 | P0–P3 | P1 |
| 现象描述 | 客户视角描述（原文） | "订单列表全部 502/504" |
| 客观指标 | 由技术支持翻译的指标 | 网关 5xx 率 100%，到达率下降 |
| 开始时间 | 故障发生时间 | 2026-01-12 09:00:54 |
| 影响范围 | 业务/用户/地域 | 订单查询接口，全量用户 |
| 变更关联 | 是否伴随变更 | 无（疑似健康检查配置漂移） |
| 定位结论 | 故障域 + 根因 | 接入层健康检查失败 |
| 处置动作 | 止损/修复动作 | 修正健康检查配置 |
| 恢复时间 | 业务恢复时间 | 09:02:40 |
| 关联 RCA | 复盘报告 | RCA-01 |
| 状态 | 处理中 / 已恢复 / 已关闭 | 已恢复 |

---

## 二、分级判定速查

| 级别 | 判定 | 首响 | 处置目标 |
|---|---|---|---|
| P0 | 核心业务全量不可用 / 数据丢失风险 | ≤ 5 分钟 | 2 小时内止损 |
| P1 | 核心功能大面积受损 | ≤ 15 分钟 | 4 小时内恢复/规避 |
| P2 | 部分功能异常 / 单实例 | ≤ 30 分钟 | 1 个工作日内 |
| P3 | 咨询 / 配置协助 | ≤ 4 小时 | 3 个工作日内 |

## 三、客户话术模板

**首响/认领**
> "您好，工单已受理，编号 #{工单号}。我们已在排查，预计 {X} 分钟内给您第一次反馈。"

**阶段性同步（P0/P1 每 15–30 分钟）**
> "当前进展：已确认影响范围是 {范围}；我们正在执行 {止损动作}；预计 {时间点} 给下一步结论。业务侧可先通过 {临时规避} 缓解。"

**方向不明时**
> "已排除 {方向A、B}，目前聚焦在 {方向C}。为加快定位，需要您协助提供 {日志/时间点/复现方式}，拿到后我优先跟进。"

**需升级/协调**
> "该问题已升级至 {二线/研发}，由 {同学} 协同处理，我作为您的主要接口人保持同步。"

**恢复后**
> "业务已恢复。根因为 {根因简述}。我们会在 {X 个工作日} 内提供正式故障复盘报告（RCA），含时间线、根因与改进项。"

**请求客户配合排查（避免"甩锅"语气）**
> "为了精准定位，麻烦您帮忙确认 {变更记录/具体报错截图/时间点}，我们同步在服务端取指标比对，双向确认更快。"

| 字段 | 内容 |
|---|---|

| 客户期望 | {恢复时间/规避方案} |

## 五、复盘通知模板

> "【故障复盘】#{工单号} 已于 {时间} 恢复。故障时长 {时长}，影响 {范围}。根因：{一句话}。改进项：{N} 条（负责人/截止时间见附件）。完整 RCA 见附件。"

---

## 六、沟通中的三条红线

1. **先止损、后根因**：故障中客户要的是恢复，不要让客户陪你一起分析代码。
2. **给预期，不给承诺之外的时间**：宁可保守，也不要反复延期。
3. **不甩锅、不隐瞒**：是配置问题就说配置问题；坦诚 + 改进项，比"已恢复"更能赢得信任。
